# hepctl

`hepctl` is a terminal app to install HEP (High Energy Physics) packages from one place.

## Quick start

```bash
go run ./cmd/hepctl
```

```bash
go run ./cmd/hepct
```

## Commands

- `install packagename`
- `help`
- `quit`
